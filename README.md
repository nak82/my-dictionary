# English Learning Site — исправленная сборка

## Состав
- `index.html` — основной сайт: регистрация/вход, словарь, «Тренажёр и Игры».
- `lessons.html` — British English Vocabulary Lab.
- `script.js`, `style.css` — скрипты и стили основного сайта.

Все файлы должны находиться в одной папке на одном домене/хостинге. Открывать сайт следует через `index.html`.

## Авторизация и синхронизация
- Регистрация и вход остаются только на главной странице. Страница уроков использует тот же `my_dict_user` и тот же Firebase Realtime Database проект.
- Основной словарь хранится в `users_data/{login}/dictionary` и `categories`.
- Vocabulary Lab хранится отдельно в `users_data/{login}/vocabularyLab/state`; настройки — в `users_data/{login}/vocabularyLab/settings`. Словари не смешиваются.
- Уроки, слова, фразовые глаголы и настройки синхронизируются между устройствами при входе под тем же логином. Локальный кэш остаётся для быстрого открытия и резервирования.
- Старые локальные данные Lab переносятся в локальный кэш пользователя. Если в облаке для пользователя данных ещё нет, локальная копия отправляется в облако.

## Важные ограничения безопасности
Сохранена прежняя самописная авторизация: пароль проверяется через `users_db/{login}`, а браузер хранит логин в `localStorage`. Это не Firebase Authentication и не является надёжным подтверждением личности на сервере. Синхронизация использует существующие правила Realtime Database. До широкого публичного использования необходимо проверить Database Rules: при текущей схеме нельзя надёжно изолировать данные только на основании `localStorage`. Не храните чувствительные данные.

## Первичная проверка после загрузки
1. Войти через главную страницу.
2. Открыть «Уроки» и проверить, что появляется статус `Synced ✓`.
3. Создать тестовый урок, изменить его, добавить слово и рейтинг.
4. Открыть сайт на другом устройстве под тем же логином и проверить появление изменений.
5. Проверить, что данные основного словаря и Vocabulary Lab остаются раздельными.

Если Firebase Rules запрещают запись в `users_data/{login}/vocabularyLab`, синхронизация покажет ошибку — потребуется скорректировать правила в консоли Firebase. Не открывайте запись/чтение всей базы публично ради обхода этой ошибки.
